- `01_数据集与样本/`
  - 论文实验使用的数据源
  - 包含 `CRUD` 官方数据与 `RGB` 本地问答数据
- `02_消融实验/`
  - 对应论文第 3 章中的主线消融与参数搜索
  - 重点看主线四档消融、最终参数搜索、RGB300 支撑结果
- `03_证伪实验/`
  - 对应论文第 3.3 节证伪实验及相关补充对比
  - 重点看主线替代路线、生成侧补充、检索侧补充、TRACE 方法对比

  - `python3 /root/Velo/experiments/生成_实验notebook.py`
