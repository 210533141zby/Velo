# 公式指标速查

这份速查表只做一件事：把论文里的公式符号，直接映射到拆解版代码中的变量和位置，方便答辩时快速定位。

## 1. 分项重排公式（论文公式 2-1）

公式：

`S_reorder(d)=0.70×R_base(d)+0.16×A(d)+0.10×C(d)+0.04×D(d)`

### 指标映射

| 论文符号 | 含义 | 在代码里看哪里 |
| --- | --- | --- |
| `R_base(d)` | 共享检索主干经过 `Rerank` 后的基础相关性分数 | 上游分数在 [m01_共享检索主干.py](/root/Velo/experiments/05_RAG算法拆解/m01_共享检索主干.py) 形成 `doc_scores`，进入分项重排后体现在 [m02_分项重排.py](/root/Velo/experiments/05_RAG算法拆解/m02_分项重排.py) 的 `rerank_score_norm` |
| `A(d)` | 对问题多个分项的覆盖情况 | 分项拆解入口是 [m02_分项重排.py](/root/Velo/experiments/05_RAG算法拆解/m02_分项重排.py) 的 `extract_query_aspect_clauses`，聚合结果体现在 `aspect_coverages` 与 `aspect_coverage` |
| `C(d)` | 对整道问题的整体覆盖度 | [m02_分项重排.py](/root/Velo/experiments/05_RAG算法拆解/m02_分项重排.py) 的 `overall_coverage` |
| `D(d)` | 时间、数字、专名、范围限定等细节信号 | [m02_分项重排.py](/root/Velo/experiments/05_RAG算法拆解/m02_分项重排.py) 的 `detail_signal` |

### 额外说明

1. 论文公式 2-1 的直接代码落点是 `build_document_reorder_breakdowns()` 与 `rerank_documents_by_paper_formula()`；
2. `R_base(d)`、`A(d)`、`C(d)`、`D(d)` 都已经在 `m02_分项重排.py` 里拆成了可见字段；
3. 讲答辩时要强调：`分项重排不是推翻精排，而是以精排结果为底座做保守修正。`

## 2. 覆盖取证公式（论文公式 2-2）

公式：

`S_select(u)=0.34×G_res(u)+0.24×H_un(u)+0.14×H_str(u)+0.10×C_q(u)+0.10×R(u)+0.08×D(u)+0.08×B_new(u)-0.16×Red(u)-0.08×P_same(u)`

### 指标映射

| 论文符号 | 含义 | 在代码里看哪里 |
| --- | --- | --- |
| `G_res(u)` | 对尚未覆盖分项的残余收益 | [m03_覆盖取证.py](/root/Velo/experiments/05_RAG算法拆解/m03_覆盖取证.py) 的 `residual_gain` |
| `H_un(u)` | 是否命中还没被覆盖的分项 | [m03_覆盖取证.py](/root/Velo/experiments/05_RAG算法拆解/m03_覆盖取证.py) 的 `uncovered_hit_ratio` |
| `H_str(u)` | 是否把覆盖偏弱的分项补强 | [m03_覆盖取证.py](/root/Velo/experiments/05_RAG算法拆解/m03_覆盖取证.py) 的 `strong_fill_ratio` |
| `C_q(u)` | 对整道问题的整体覆盖 | [m03_覆盖取证.py](/root/Velo/experiments/05_RAG算法拆解/m03_覆盖取证.py) 的 `overall_coverage` |
| `R(u)` | 上游基础相关性分数 | [m03_覆盖取证.py](/root/Velo/experiments/05_RAG算法拆解/m03_覆盖取证.py) 的 `rerank_score` |
| `D(u)` | 细节强度 | [m03_覆盖取证.py](/root/Velo/experiments/05_RAG算法拆解/m03_覆盖取证.py) 的 `detail_signal` |
| `B_new(u)` | 新文档带来的新增信息奖励 | [m03_覆盖取证.py](/root/Velo/experiments/05_RAG算法拆解/m03_覆盖取证.py) 的 `new_doc_bonus` |
| `Red(u)` | 与已选证据的重复程度 | [m03_覆盖取证.py](/root/Velo/experiments/05_RAG算法拆解/m03_覆盖取证.py) 的 `redundancy` |
| `P_same(u)` | 在同一文档内部重复打转的惩罚 | [m03_覆盖取证.py](/root/Velo/experiments/05_RAG算法拆解/m03_覆盖取证.py) 的 `same_doc_penalty` |

### 一句话记忆

覆盖取证不是“拿总分最高的几条”，而是：

`优先补还没补到的分项，同时压低重复证据和同文档来回打转的证据。`
