# 按题作答

这份说明只讲论文里的“按题作答”，并且直接按论文口径来写。

## 1. 它在论文里的位置

按题作答发生在分项重排和覆盖取证之后，是最终回答生成阶段的控制层。

它不是多轮思维链，也不是支持表二次综合，而是：

`在同一次回答里，让模型更严格地按题目要求履约。`

## 2. 它到底控制什么

按题作答主要控制三件事：

1. 当前问题属于哪类任务；
2. 题目里大概有几个并列要求；
3. 最终答案应该按什么顺序展开，才能尽量贴着题目作答。

### 3.2 每个函数负责什么

1. `infer_query_task_mode`：先判断这是事实定位、概括、修订还是默认问答；
2. `estimate_parallel_requirement_count`：粗略估计问题里有几个并列要求；
3. `build_task_aligned_answer_prompt`：按照任务类型和并列要求组织提示词；
4. `build_answer_prompt`：统一做提示词风格分发；
5. `generate_answer`：最终调用本地回答模型输出答案。

## 4. 最关键的一句怎么讲

如果老师问“按题作答是不是又多加了一轮生成”，可以直接回答：

`不是。按题作答本质上还是单轮回答，只是在回答前先做任务识别、并列要求估计和提示词组织，让模型按题目结构履约。`
