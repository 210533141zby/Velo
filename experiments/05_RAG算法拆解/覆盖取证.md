# 覆盖取证

这份说明只讲论文里的“覆盖取证”，并且直接按论文口径来写。

## 1. 它在论文里的位置

覆盖取证发生在分项重排之后、按题作答之前，也就是：

`Dense + BM25 -> RRF -> Rerank -> 分项重排 -> 覆盖取证 -> 按题作答`

它解决的问题不是“谁先排前面”，而是：

`这些已经比较靠前的候选里，最后究竟留下哪几条局部证据送进回答模型。`

## 2. 论文公式

论文公式 2-2 为：

`S_select(u)=0.34×G_res(u)+0.24×H_un(u)+0.14×H_str(u)+0.10×C_q(u)+0.10×R(u)+0.08×D(u)+0.08×B_new(u)-0.16×Red(u)-0.08×P_same(u)`

其中：

1. `G_res(u)`：对尚未覆盖分项带来的残余收益；
2. `H_un(u)`：是否命中了还没覆盖到的分项；
3. `H_str(u)`：是否把覆盖偏弱的分项补强；
4. `C_q(u)`：对整道问题的整体覆盖；
5. `R(u)`：上游基础相关性分数；
6. `D(u)`：细节强度；
7. `B_new(u)`：新文档带来的新增信息奖励；
8. `Red(u)`：与已选证据的重复程度；
9. `P_same(u)`：在同一文档内部打转的惩罚。

## 3. 它到底解决什么问题

即使分项重排已经把更均衡的文档提到前面，也不能直接把这些长文档整篇送进回答模型。因为：

1. 文档太长；
2. 不同文档之间经常高度重复；
3. 真正有用的信息只集中在少数局部窗口里。

因此，覆盖取证的核心不是“拿总分最高的几条”，而是：

`优先补尚未覆盖的分项，同时压低重复内容。`

## 5. 最关键的一句怎么讲

如果老师问“覆盖取证和普通 top-k 最大区别是什么”，可以直接回答：

`普通 top-k 是看静态总分，覆盖取证是持续跟踪“哪些分项还没补到”，优先补残余收益最大的证据。`
