# 02_消融实验

这一层对应论文第 3 章中的主线消融、参数搜索和 RGB300 支撑实验。

## 先看哪里

1. `scripts/运行_主线四档消融.ipynb`
   - 可直接查看完整代码和对应结果预览
2. `scripts/运行_主线四档消融.py`
   - 对应论文主线从基线到“分项重排 + 覆盖取证 + 按题作答”的四档提升
3. `results/01_主线四档消融_20260517/`
   - 重点看：
   - `消融实验_汇总.json`
   - `消融实验_指标表.json`
   - `评测批次说明.json`
4. `scripts/运行_最终参数搜索.ipynb`
   - 可直接查看代码和参数搜索结果预览
5. `scripts/运行_最终参数搜索.py`
   - 对应 4/6、5/7 等参数组合比较
6. `results/02_最终参数搜索_20260517/`
   - 重点看：
   - `参数搜索_路线总表.json`
   - `参数搜索_全部汇总.json`
7. `scripts/运行_RGB300支撑评测.ipynb`
   - 可直接查看代码、指标表和图像预览
8. `scripts/运行_RGB300支撑评测.py`
   - 对应 RGB300 稳定性支撑实验
9. `results/03_RGB300支撑结果/`
   - 重点看：
   - `支撑实验_汇总.json`
   - `RGB300_柱状图.svg`
   - `CRUD对照_柱状图.svg`
